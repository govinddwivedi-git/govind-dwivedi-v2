# Govind Dwivedi — Engineering Portfolio

Personal developer portfolio built with React, Vite, and Tailwind CSS. It presents engineering experience, projects, skills, education, contact links, and competitive-programming profiles in an editorial, responsive interface.

## Features

- Responsive portfolio layout with animated section transitions.
- Experience, projects, skills, education, and contact sections.
- Shared technology icon catalog across the Skills and Projects sections.
- CodeChef and Codeforces profile data loaded from their public APIs.
- GeeksForGeeks profile card backed by a clearly labeled hardcoded snapshot.
- Accessible navigation with scroll-spy state, focus styles, and reduced-motion support.

## Tech stack

- React 18
- Vite 6
- Tailwind CSS 3
- Framer Motion
- Lucide React
- React Icons
